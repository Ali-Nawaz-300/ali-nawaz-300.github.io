# Ali Nawaz — Portfolio

A responsive, dependency-free portfolio built with HTML, CSS and JavaScript. Includes About, skills, RescuePet's three-part workflow, Student Expense Tracker, CodeMate AI, experience, education, and LinkedIn contact links.

## Preview

Open `index.html` in a browser. Keep `styles.css`, `script.js`, and the `assets` folder alongside it. No installation or build command is required.

## Publish on GitHub Pages

1. Sign into GitHub as `Ali-Nawaz-300`.
2. Create a public repository named `ali-nawaz-300.github.io`. If it already exists, review its contents before replacing anything.
3. Upload the contents of this folder, not the enclosing folder. `index.html` must be at the repository root, alongside `styles.css`, `script.js`, and `assets/ali-nawaz.png`.
4. In the repository's Settings → Pages, choose Deploy from a branch, then `main` and `/ (root)`. Save.
5. Wait for GitHub's Pages deployment to finish and use the website URL shown there. The intended address is `https://ali-nawaz-300.github.io/`; it is not live merely because these files have been created.

## Content updates

- Edit visible text and profile/project links in `index.html`.
- Edit colors, layouts and responsive breakpoints in `styles.css`.
- Replace `assets/ali-nawaz.png` to change the portrait.
- The contact section uses LinkedIn; no email, public resume, or contact-form backend is included.
- RescuePet has no repository link, API keys, or source code in this site.
- Internship completion is included without invented start/end dates. Confirm exact dates before adding them.
- Project descriptions reflect the supplied overview, not a source-code audit. Review Student Expense Tracker and CodeMate AI wording before publication.

The site uses local assets and system fonts, with no third-party scripts or tracking. Navigation works without JavaScript; JavaScript adds the mobile menu and current footer year.
